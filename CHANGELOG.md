# AgencyOS — Changelog

## [1.0.0] - Initial Release
- **Foundations**: Initialized React 19 + Express full-stack architecture with Vite middlewares.
- **Design System**: Warm Ivory (`#F7F5F0`), Cream, and Buttery Yellow (`#F6B91A`) design tokens with Zero-Pill typography.
- **Data Engine**: Transactional persistent JSON database with synthetic agency seed dataset.
- **Admin Workspace**:
  - Dashboard with real database-backed KPIs, revenue chart, status donut, and activity stream.
  - Project management with lifecycle states, budget tracking, and task progress calculation.
  - Task Kanban board with 4 workflow stages and assignment controls.
  - CRM lead pipeline with multi-stage deal tracking and 1-click lead-to-client conversion.
  - Client roster with linked project portfolios.
  - Team directory with role and status management.
  - Notifications center with real event generation.
  - Workspace settings.
- **Client Portal**:
  - Dedicated client view for client accounts (Marcus Vance @ Acme Corp).
  - Project milestones and deliverable review.
  - Client feedback and revision submission workflow.
  - Invoice and payment status records.
- **Demo Switcher**: 1-click persona toggling in header for Admin, Team Member, and Client views.
