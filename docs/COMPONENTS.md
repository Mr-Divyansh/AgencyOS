# AgencyOS — Component Inventory

## Navigation & App Shell
- `TopBar`: 3-Zone top navigation with brand wordmark, breadcrumbs, search, notification trigger, and persona switcher.
- `Sidebar`: Desktop persistent sidebar and mobile slide-over drawer with route links and active indicator.
- `PersonaSwitcher`: Dropdown in header allowing 1-click toggling between Admin, Team Member, and Client personas.

## Data Display & Layout
- `MetricCard`: KPI card displaying label, tabular numeric value, period comparison indicator, and icon.
- `RevenueChart`: Clean SVG line & area chart displaying monthly billings with hover data point.
- `StatusDonut`: Clean SVG donut chart displaying project status breakdown.
- `KanbanColumn`: Column container for task cards with status counter and drop target.
- `TaskCard`: Task card with priority indicator, assignee avatar, due date, and quick status mover.
- `LeadCard`: CRM lead card with deal value, service interest, and pipeline stage changer.

## Interactive Primitives
- `Modal`: Accessible modal dialog with backdrop, focus trapping, and keyboard escape.
- `SegmentedTabs`: Accessible filter tabs with active highlight.
- `Badge`: Clean status indicator adhering to semantic status guidelines.
- `Button`: Primary (buttery yellow), Secondary (white outline), Destructive (subtle crimson).
