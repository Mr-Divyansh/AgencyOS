# Instructions for AI Coding Agents

1. **Identity & Boundaries**: Never inject AI chatbot widgets, floating AI assistant buttons, or prompt fields into the application unless explicitly requested by the user.
2. **Design Language**: Follow the Warm Ivory & Buttery Yellow system. Never default to generic purple AI slop, glassmorphism, or static pill metadata sandwiches.
3. **Full-Stack Execution**: Express server runs from `server.ts` mounting Vite in development (`tsx server.ts`). Port 3000 is required.
4. **Data Persistence**: State must persist in `data/database.json`. Never delete demo seed integrity.
